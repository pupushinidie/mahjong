# 麻将

麻将系列的网页联机版：一个仓库、一个服务进程，进去以后先选玩法：**四川麻将**（血战到底 / 血流成河）和**立直麻将**（日本麻将，雀魂段位战习惯）。线上 https://gulugagame.com/mahjong/ 。

规则书在 `~/Desktop/游戏规则/`：《麻将系列总览.md》《四川麻将.md》《立直麻将.md》。规则书里标 ⚠️ 的待确认项全部按规则书的推荐默认值做（他 2026-10-08 拍板），见下面的表。

## 结构

npm workspaces 单仓库：

- `packages/game`：纯规则引擎，`apply(state, playerId, command) → state`，不改输入，种子随机数存在状态里。
  - `tiles.ts`：牌的编码（整个系列共用）。牌种 0–33（万 0–8、筒 9–17、条 18–26、东南西北白发中 27–33），每张牌 0–135（`tile >> 2` 是牌种），立直的红五是 16、52、88，隐藏的牌是 -1。
  - `hand.ts`：麻将内核（共用）：标准型拆解、七对、国士、听牌、向听数（按门缓存）、有效牌。
  - `sichuan.ts` / `sichuan-score.ts` / `sichuan-bot.ts`：四川麻将的引擎、算番、机器人。
  - `riichi.ts` / `riichi-score.ts` / `riichi-bot.ts` / `riichi-types.ts`：立直麻将的引擎（王牌、宝牌、吃碰杠、立直、振听、流局、终局条件）、役和符点数、机器人。
  - `engine.ts`：统一入口（`createGame`、`applyCommand`、`resolveClaim`、`timeoutTurn`、`pendingSeats`、`botCommand`、`redactGameForViewer`、`legalCommands`、`scoreOf`），按 `state.variant` 分发。
- `apps/server`：Socket.IO 房间服务器。始终 4 个座位，1–4 个真人，**开局时空座由机器人补满**；机器人、托管、离线的人都由服务器按 0.5–1.5 秒的节奏代打（`botCommand`）。每张弃牌后抢牌窗口至少开 0.8 秒再结算（所有人都一样，看不出谁能碰能胡）。
- `apps/web`：Vite + React。首页选玩法 → 等候房间（房主改开房选项）→ 牌桌（四川 `GameBoard.tsx`、立直 `RiichiBoard.tsx`，共用 `table.ts` 的尺寸计算，样式都在 `mahjong.css`）。
- `scripts/test-bot.mjs`：模拟真人连进房间的陪玩脚本（用法见文件开头）。
- `art/`：`tiles.py` 用代码画牌面图集（牌面字用繁体像素字体写），`r1.py` PixelLab 出场景和头像候选，`export.py` 按 `selection.json` 导出，`ledger.jsonl` 记账。

常用命令：`npm run dev`（服务 3012、网页 5185）、`npm test`、`npm run typecheck`、`BASE_PATH=/mahjong/ npm run build`。

## 四川麻将：默认规则（规则书第 11 节的待确认项）

| 项目 | 做法 |
|---|---|
| 自摸 | 默认加 1 番；开房可选「加底」（不加番，每家多付 1 分） |
| 龙七对 | 七对 + 根，按叠加算（不单独定倍数） |
| 杠上花、海底捞月 | 照加自摸的 1 番；杠上花和海底不叠加 |
| 花猪 | 赔给每个不是花猪的人 16 分；开了封顶时取 min(16, 2^封顶) |
| 查叫、查花猪的范围 | 血战只在还在局中的人之间；血流里和过牌的人算听牌、不是花猪、不退税 |
| 退税 | 退给当初付杠分的人（包括已经下桌的人） |
| 一炮多响的呼叫转移 | 杠分全部转给从放炮人逆时针最近的那个和牌人 |
| 连杠后放炮 | 只转移最后一次杠的杠分 |
| 缺门 | 手里有缺门牌时只能打缺门（程序限制）；缺门牌不能碰杠 |
| 过胡 | 放过能胡的牌（含抢杠），到自己下次摸牌前不能胡别人的牌；自摸不受限。血流锁定后放弃自摸也算 |
| 天胡、地胡 | +5 番，不再另加自摸；地胡只算闲家第一次摸牌自摸、之前没人碰杠 |
| 封顶 | 默认不封顶，开房可选 3 / 4 / 6 番 |
| 换三张方向 | 给下家、上家、对家各 1/3 |
| 最后一张弃牌 | 能胡（不加番），不能碰杠 |
| 带幺九 | 只算标准型，七对不算 |
| 盘数 | 4 / 8 / 16 盘，默认 8；累计积分最高获胜，同分并列 |
| 下一盘庄家 | 第一次和牌只有一人 → 他；第一次就是一炮多响 → 放炮的人；流局 → 庄家连庄 |

其他实现细节：

- 血流成河：和了以后手牌锁定，不能和也不能杠时自动摸切；杠要求杠完听的牌完全不变。和的牌放进和牌区，下桌和锁定的人手牌对所有人公开。
- 隐藏信息只通过 `redactGameForViewer` 下发：别人的手牌（只给张数）、牌墙顺序、别人的暗杠（牌面和事件里的牌都给 -1）、换三张选的牌（只有自己和交换的双方知道）、定缺（所有人选好前保密）、抢牌窗口（只给自己的选项，待回应人数也只给自己）。抢牌窗口的倒计时也只发给自己有选项的人。
- 积分只是游戏分，界面不出现金额、筹码。

## 立直麻将：规则版本和默认值

按规则书（雀魂段位战习惯）：25000 点起、30000 点返，3 张红五（开房可关），有食断（开房可关），半庄战或东风战，不切上满贯，累计役满，双倍役满，多家荣和（上家取本场和供托），击飞，西入（突然死亡，最多到西 4 局；东风战是南入到南 4 局），南 4 局庄家一位自动结束（和了止 / 听牌止）。规则书 ⚠️ 待确认项按推荐默认值：

| 项目 | 做法 |
|---|---|
| 流局满贯 | 有流局满贯时不再收付听牌罚符；不加本场 |
| 连风牌雀头 | 4 符 |
| 立直需要的牌墙余量 | 至少 4 张 |
| 国士抢暗杠 | 可以 |
| 暗杠 | 公开牌种（显示时两头扣着） |
| 杠宝 | 暗杠马上翻；明杠、加杠在开杠的人打牌后翻 |
| 和了止 / 听牌止 | 自动结束 |
| 人和、古役 | 不采用 |
| 三家和 | 允许 |
| 立直后暗杠 | 只要求听的牌不变 |
| 振听 | 舍张振听；放过自己听的牌（只看牌型，不管有没有役）→ 到自己下次打牌前同巡振听；立直后放过 → 整局立直振听 |
| 最终得分 | (点数 − 30000) / 1000 + 马（+15 / +5 / −5 / −15），第一名 +20，只显示 |

其他：每张弃牌后、加杠和暗杠后都一律开抢牌窗口（固定停顿），别人看不出谁能荣和、能抢杠。别人的振听状态、包牌记录不下发。荒牌流局时听牌的人亮牌。

玩家开关（右栏，存在本机）：自动和牌、不吃碰杠、自动摸切。出牌和立直都是先选中再确认（立直：点「立直」进入立直模式，只能选打出后还听牌的牌）。

## 限时和托管

立直：每手 5 秒，用完扣这一局的 20 秒备用时间（服务端按人记，换局重置），备用时间也用完就超时：能和自动和，吃碰杠一律过，出牌摸切（吃碰后打最右边能打的牌）。立直以后不能和的牌自动摸切。

四川：

| 阶段 | 限时 | 超时 |
|---|---|---|
| 换三张 | 20 秒 | 按机器人选（张数最少但不少于 3 张的那门里最孤立的 3 张） |
| 定缺 | 10 秒 | 张数最少的那门（一样多按 条 → 筒 → 万） |
| 出牌 | 15 秒 | 能自摸就自摸；有缺门打缺门里离 5 最远的，否则摸切 |
| 碰杠胡 | 8 秒（只对有选项的人） | 能胡自动胡，碰杠一律过 |
| 结算 | 30 秒 | 自动下一盘 |

连续超时 2 次转托管（牌桌上点「取消托管」接回）；掉线的人 1 秒后由机器人代打，用原昵称和房间码回来接上。机器人：向听数贪心（先打缺门、再按向听数和有效牌），碰杠不增加向听数就做，能胡就胡。
立直的机器人：向听数贪心（七对子、国士也算；尽量留宝牌和红五，先打客风字牌），役牌能碰就碰，其他吃碰要「副露以后还有役」并且向听数减少，听牌就立直，有人立直而自己向听数 ≥ 2 时先打现物，九种九牌就流局，能和就和。

## 美术

- 牌面：代码画的像素牌（`art/tiles.py`，20×32，牌面 + 4 像素牌身厚度）。牌面上的字用繁体（萬、東、發，他 2026-10-09 定的），Fusion Pixel 12px 写，只按整数倍显示。一条的小鸟是代码画的。字牌、红五也已经画好，给立直用。

- 立直（我挑的，他还没看）：日式雀庄场景夜间 `jansou-night2-s82`（第一批 4 张、第二批另外 3 张有乱码招牌或像字的告示，没用）、白天 `jansou-day-s71`；头像 `avatar-jp` 64 选 4：21、7、27、60（粉色头发那几个像麻将动画角色，没用）。
- 选择记在 `art/selection.json`，`python art/export.py` 导出；候选在 `art/out/r1/`。
