# 麻将

麻将系列的网页联机版：一个仓库、一个服务进程，进去以后先选玩法。现在能玩的是**四川麻将**（血战到底 / 血流成河），**立直麻将**（日本麻将）在做，选玩法页上显示「制作中」。线上 https://gulugagame.com/mahjong/ 。

规则书在 `~/Desktop/游戏规则/`：《麻将系列总览.md》《四川麻将.md》《立直麻将.md》。规则书里标 ⚠️ 的待确认项全部按规则书的推荐默认值做（他 2026-10-08 拍板），见下面的表。

## 结构

npm workspaces 单仓库：

- `packages/game`：纯规则引擎，`apply(state, playerId, command) → state`，不改输入，种子随机数存在状态里。
  - `tiles.ts`：牌的编码（整个系列共用）。牌种 0–33（万 0–8、筒 9–17、条 18–26、东南西北白发中 27–33），每张牌 0–135（`tile >> 2` 是牌种），立直的红五是 16、52、88，隐藏的牌是 -1。
  - `hand.ts`：麻将内核（共用）：标准型拆解、七对、国士、听牌、向听数（按门缓存）、有效牌。
  - `sichuan.ts` / `sichuan-score.ts` / `sichuan-bot.ts`：四川麻将的引擎、算番、机器人。
  - `engine.ts`：统一入口（`createGame`、`applyCommand`、`resolveClaim`、`timeoutTurn`、`pendingSeats`、`botCommand`、`redactGameForViewer`、`legalCommands`），按 `state.variant` 分发。立直麻将之后加 `riichi*.ts` 挂在这里。
- `apps/server`：Socket.IO 房间服务器。始终 4 个座位，1–4 个真人，**开局时空座由机器人补满**；机器人、托管、离线的人都由服务器按 0.5–1.5 秒的节奏代打（`botCommand`）。每张弃牌后抢牌窗口至少开 0.8 秒再结算（所有人都一样，看不出谁能碰能胡）。
- `apps/web`：Vite + React。首页选玩法 → 等候房间（房主改开房选项）→ 牌桌（`GameBoard.tsx`，样式 `mahjong.css`）。
- `scripts/test-bot.mjs`：模拟真人连进房间的陪玩脚本（用法见文件开头）。
- `art/`：`tiles.py` 用代码画牌面图集（万字用像素字体写），`r1.py` PixelLab 出场景和头像候选，`export.py` 按 `selection.json` 导出，`ledger.jsonl` 记账。

常用命令：`npm run dev`（服务 3012、网页 5185）、`npm test`、`npm run typecheck`、`BASE_PATH=/mahjong/ npm run build`。

## 四川麻将：默认规则（规则书第 11 节的待确认项）

| 项目 | 做法 |
|---|---|
| 自摸 | 默认加 1 番；开房可选「加底」（不加番，每家多付 1 分） |
| 龙七对 | 七对 + 根，按叠加算（不单独定倍数） |
| 杠上花、海底捞月 | 照加自摸的 1 番；杠上花和海底不叠加 |
| 花猪 | 赔给每个不是花猪的人 16 分；开了封顶时取 min(16, 2^封顶) |
| 查叫、查花猪的范围 | 血战只在还在局中的人之间；血流里和过牌的人算听牌、不是花猪、不退税 |
| 退税 | 退给当初付杠分的人（包括已经下桌的人） |
| 一炮多响的呼叫转移 | 杠分全部转给从放炮人逆时针最近的那个和牌人 |
| 连杠后放炮 | 只转移最后一次杠的杠分 |
| 缺门 | 手里有缺门牌时只能打缺门（程序限制）；缺门牌不能碰杠 |
| 过胡 | 放过能胡的牌（含抢杠），到自己下次摸牌前不能胡别人的牌；自摸不受限。血流锁定后放弃自摸也算 |
| 天胡、地胡 | +5 番，不再另加自摸；地胡只算闲家第一次摸牌自摸、之前没人碰杠 |
| 封顶 | 默认不封顶，开房可选 3 / 4 / 6 番 |
| 换三张方向 | 给下家、上家、对家各 1/3 |
| 最后一张弃牌 | 能胡（不加番），不能碰杠 |
| 带幺九 | 只算标准型，七对不算 |
| 盘数 | 4 / 8 / 16 盘，默认 8；累计积分最高获胜，同分并列 |
| 下一盘庄家 | 第一次和牌只有一人 → 他；第一次就是一炮多响 → 放炮的人；流局 → 庄家连庄 |

其他实现细节：

- 血流成河：和了以后手牌锁定，不能和也不能杠时自动摸切；杠要求杠完听的牌完全不变。和的牌放进和牌区，下桌和锁定的人手牌对所有人公开。
- 隐藏信息只通过 `redactGameForViewer` 下发：别人的手牌（只给张数）、牌墙顺序、别人的暗杠（牌面和事件里的牌都给 -1）、换三张选的牌（只有自己和交换的双方知道）、定缺（所有人选好前保密）、抢牌窗口（只给自己的选项，待回应人数也只给自己）。抢牌窗口的倒计时也只发给自己有选项的人。
- 积分只是游戏分，界面不出现金额、筹码。

## 限时和托管

| 阶段 | 限时 | 超时 |
|---|---|---|
| 换三张 | 20 秒 | 按机器人选（张数最少但不少于 3 张的那门里最孤立的 3 张） |
| 定缺 | 10 秒 | 张数最少的那门（一样多按 条 → 筒 → 万） |
| 出牌 | 15 秒 | 能自摸就自摸；有缺门打缺门里离 5 最远的，否则摸切 |
| 碰杠胡 | 8 秒（只对有选项的人） | 能胡自动胡，碰杠一律过 |
| 结算 | 30 秒 | 自动下一盘 |

连续超时 2 次转托管（牌桌上点「取消托管」接回）；掉线的人 1 秒后由机器人代打，用原昵称和房间码回来接上。机器人：向听数贪心（先打缺门、再按向听数和有效牌），碰杠不增加向听数就做，能胡就胡。

## 美术

- 牌面：代码画的像素牌（`art/tiles.py`，20×32，牌面 + 4 像素牌身厚度；万字是 Fusion Pixel 12px），只按整数倍显示。一条的小鸟是代码画的。字牌、红五也已经画好，给立直用。
- 场景（PixelLab pixen 512×288）：夜间 `teahouse-night-s32`（灯笼茶馆）、白天 `teahouse-day-s42`（竹帘阳光），做牌桌背景和首页主图。
- 头像（PixelLab generate-image-v2，64 选 4）：13、0、38、21。
- **美术是我挑的，他还没看**；候选图在 `art/out/r1/`（场景对比图 `art/out/r1-scenes.png`、头像 `art/out/r1-avatars.png`）。
